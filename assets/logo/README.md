# REVamp logo

The mark is two rewind arrows and a play triangle that together form an R ("rev" + play).

| File | Use |
|---|---|
| `logo.svg` | Mark + wordmark for dark backgrounds |
| `logo-light.svg` | Mark + wordmark for light backgrounds |
| `mark.svg` | Mark only |
| `mono.svg` | One-colour mark |
| `icon.svg`, `icon-*.png` | Rounded-square app icon (32 to 1024 px) |
| `../social-card.png` | GitHub social preview, 1280×640 |
